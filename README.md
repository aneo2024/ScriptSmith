# ScriptSmith

剧本 AI 辅助创作平台。前端 React + Ant Design，后端 Go + Gin，AI 对接多提供商。

## 项目结构

```
frontend/    React 前端 (Vite + Ant Design + React Router)
backend/     Go 后端 (Gin + GORM + 多 AI Provider)
```

## AI 生成功能 & 上下文问题

当前 4 个 AI 生成函数各自只看自己的数据，**不做跨层上下文注入**：

| 函数 | 拿到什么 | 缺什么 |
|---|---|---|
| 剧集梗概 | 当前剧集的全部场景 | 不看作品 synopsis、不看前集梗概 |
| 角色外貌 | 当前剧集角色列表 + 场景摘要（每场截 60 字） | 不看作品整体剧情、不看其他剧集 |
| 场景环境 | 当前剧集场景列表（标题/地点/类型/时间） | 不看角色关系、不看前后场情绪 |
| 人物小传 | 全部剧集角色列表 + 最多 300 字剧情摘要 | 不看具体场景内容 |

## 改进方向

### 1. 全量上下文注入（当前即可做）

把该给的数据都塞进 prompt，不做截断：

- 人物小传：传入该角色在所有剧集中的关键场景和对话
- 剧集梗概：传入前一集梗概，让 AI 写"承接上文"
- 场景环境：传入前后场景的动作和对话，推气氛
- 角色外貌：传入角色已有设定，保证一致性

### 2. RAG（数据量大时再上）

把每集场景的 action + dialogue 向量化，用角色名 / 剧情关键词做检索。当前项目规模不需要。

## 运行

```bash
# 前端
cd frontend && npm install && npm run dev    # localhost:5173

# 后端
cd backend && go run ./cmd/server            # localhost:8080
```
