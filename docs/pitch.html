项目概述

做什么的

基于大语言模型的全栈 Web 应用，将小说文本转换为结构化影视剧本。支持 7 种格式、11 种改编风格，覆盖角色管理、人物小传生成、剧本编辑与 YAML 导出。

技术规模

前端 React 19 + Zustand + Ant Design，后端 Go 1.25 + Gin + GORM，数据库 SQLite / PostgreSQL 双模式。Docker Compose 三容器一键部署。

设计哲学

AI 负责重复劳动——结构转换、风格改编、角色生成。作者保留全部控制权：选择用什么风格、什么时候调用 AI、认不认可 AI 的修改。

开发背景

XEngineer 竞赛题目：AI + 创作工具。从选题到完整交付，独立完成前后端全栈开发。

双数据库策略

开发：SQLite 零配置，scriptsmith.db 单文件备份即全量。生产：PostgreSQL 16，DB_TYPE 环境变量切换。GORM AutoMigrate 启动即建表。

JWT 安全设计

Access Token + Refresh Token。一次性轮换：每次刷新返回新 token，旧 token 立即失效。防止被盗后长期滥用。

AI Provider 抽象

接口抽象，默认集成 DeepSeek。用户自行配置任意 OpenAI 兼容 API，支持连接测试和设为默认。

Docker 一键部署

docker compose up -d 三容器：PostgreSQL + Go 后端 + Nginx。多阶段构建，镜像分层缓存。

前端设计：交互与技术选型

状态管理：Zustand + 乐观更新

剧本编辑器状态由 Zustand store 统一管理。用户双击修改 → 本地 store 立即生效 → 异步 PUT。失败从服务端拉取回滚，几乎感知不到网络延迟。

自定义 Hooks：useTask 轮询

封装 useTask hook 管理任务生命周期。2s 间隔轮询，完成自动跳转编辑器。状态持久化到 localStorage，离开页面回来继续。

结构化编辑器设计

不做自由文本编辑器，做领域专用编辑器。左侧场景导航，右侧按内容块类型分色渲染。双击进入内联编辑，Esc 取消、Ctrl+Enter 保存。

按需调用 AI 的 UI

AI 功能不自动触发。三个独立按钮——外貌 / 小传 / 生平。用户决定何时调用、调用哪个。每次明确消耗 token，不满意可重新生成。

核心功能

小说转剧本：多格式 × 多风格

怎么做的

7 种格式（电影 / 电视剧 / 舞台剧 / 动画 / 短片 / 网剧 / 纪录片）× 11 种改编风格。前端枚举选择 → 后端 prompt 映射 → AI 输出统一结构。

亮点在哪

格式和风格是剧本改编的基础决策。做成下拉选项，用户不需要自己组织 prompt 来描述想要什么格式、什么风格——直接选，专注写内容。

核心功能

结构化剧本编辑

怎么做的

左侧场景导航按顺序列出所有场次，点击切换。右侧展示 slugline（内 / 外景 · 地点 · 时间）、内容块（动作 / 对白 / 转场 / 音效 / 备注）。双击任意字段直接编辑，不同类型块用不同颜色区分。

录制建议：场景导航切换 + 双击编辑对白 + 颜色区分

亮点在哪

剧本不是长文本，是有结构的。场景、对白、动作各司其职。按场景和内容块维度操作，而不是在一大段文字里找某句台词。改完本地即时刷新，后台异步保存。

核心功能

角色深化：从设定到小传

怎么做的

角色分四个维度：外貌、性格、背景、生平。独立字段存储，互不干扰。三个独立按钮分别触发 AI 生成。人物小传页面展示完整角色画像，可手动编辑。

录制建议：点击生成按钮 → 角色卡片刷新 → 小传页面

亮点在哪

信息拆成独立字段后，编辑器、YAML 导出、人物小传各取所需。按需调用 AI，不想生成就不点，不满意再点一次，不浪费 token。

核心功能

多集管理：两层存储

怎么做的

作品层存角色人设卡，对所有剧集生效。剧集层存每集特有数据。点「转新的一集」自动创建，删除后自动重新编号。

亮点在哪

两层存储让角色信息改一次全剧同步。多集切换下拉栏在编辑器顶部，用户只管创作，不用管数据怎么存的。

核心功能

改编备注：让 AI 有据可查

怎么做的

AI prompt 强制输出改编日志：改了哪里、怎么改的、为什么这么改。存为结构化字段，前端浮窗随时展开查看。

亮点在哪

把每次修改的理由写出来，判断权交还给作者。认可就保留，不认可就改回去。有据可查才敢放心用 AI。

演示流程

1封面 → 仪表盘

莎士比亚名言 + 森林渐变背景，不催注册先展示氛围。环岛数据绕头像浮动，点击直接跳转。

2提交小说

粘贴小说文本，下拉选格式和风格，点「开始转换」。进度条实时反馈，关页面不中断。

3编辑剧本

左侧场景导航，右侧内容块按颜色区分。双击改对白 / 场景信息，浮窗查看改编备注。

4角色深化

外貌 → 小传 → 生平，三按钮独立触发。小传页面 AI 写完整生平，可手动编辑。

5导出 YAML

一键下载标准 YAML，兼容 Final Draft、Trelby 等制片软件和 Git 版本控制。

6灵感栏目

AI 生成创作知识文章，每日推荐话题，按话题聚合浏览。
